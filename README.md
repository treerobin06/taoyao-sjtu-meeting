# SJTU 云视频会议工具箱

> 上海交通大学云视频会议平台（meeting.sjtu.edu.cn）的批量管理油猴脚本，专为科研课题组、教研室、需要每周/每学期定期开多个会议的场景设计。一站式：批量创建、批量导出、批量删除、邀请链接缓存、ICS 日历导出。

---

## 这工具箱解决什么痛点

如果你像我们课题组一样，每学期要给十几个不同主题的固定会议（组会、产品会、SEA、cs is、不同导师的 group meeting……）在 SJTU 云视频会议平台上**一次性建出整学期 60+ 个会议**，并且每天/每周还要把当天的会议链接复制发到微信群——

- 你大概率经历过：在 SJTU 后台一个一个会议手工填表 → 30+ 次重复劳动
- 或者：每天会议前去找会议号、密码、邀请链接 → 一条条往群里粘

这个工具箱**帮你一次配好预设、一次创建一整学期，每天 3 秒钟把当天会议邀请发出去**。

---

## 🎁 功能总览

| 区域 | 能力 |
|---|---|
| **📅 批量创建** | 多任务行（不同主题/不同时间段），按日期范围 + 重复星期展开成 N 个会议；按时间排序逐个提交；支持中途取消、跨页面恢复 |
| **📋 列表与导出** | 自动扫描页面表格；按主题/日期/预设/今天/明天筛选与勾选；snapshot 提取（瞬间）/ 含入会链接提取（首次抓取后自动缓存，后续秒级）/ ICS 文件下载（导入 Apple/Google 日历）/ 自定义输出模板 |
| **📦 预设 / 标签** | 把单行任务保存为可复用预设，给预设打 tag（"本学期"、"组会"、"产品会"……）；按 tag 筛选 + 一键加载该 tag 全部预设到任务列表 |
| **🗑 回收站** | 删除前自动归档（含完整邀请文本），随时查看历史删除记录、检索曾经的会议号 |
| **原生批量删除** | 用页面顶部"批量删除"按钮 + 自动确认，秒级删完 N 条，比逐条点删除快得多 |
| **学期范围** | 一次设置"起点日期 + 周数"，所有任务行/预设加载都用这个范围 |
| **共享配置** | 默认密码、默认联席主持人、操作间隔等全局配置持久化在浏览器 localStorage |

## 🛠 安装步骤

### 第 1 步：安装 Tampermonkey（油猴）

Tampermonkey 是浏览器扩展，让你能给网页注入自定义 JavaScript 脚本。本工具箱就是一个油猴脚本。

按你用的浏览器选一个：

| 浏览器 | 安装链接 |
|---|---|
| **Microsoft Edge** | [Edge 加载项商店](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) |
| **Google Chrome** | [Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| **Mozilla Firefox** | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/) |
| **Safari** | [Mac App Store](https://apps.apple.com/app/tampermonkey/id1482490089)（付费，¥18） |

安装完浏览器右上角会出现一个 ⚫ 黑色方框图标（Tampermonkey logo）。

> 💡 **小白提示**：安装可能需要在 Chrome / Edge 的扩展页面里手动开启"开发者模式"。具体看 [Tampermonkey 官方文档](https://www.tampermonkey.net/faq.php#Q200)。

### 第 2 步：安装本工具箱脚本

**方法 A · 一键安装（推荐）**

直接点这个链接，Tampermonkey 会自动弹出安装页：

> 👉 [点这里安装最新版](https://github.com/treerobin06/sjtu-meeting-toolkit/raw/main/sjtu-meeting-toolkit.user.js)

在弹出的页面点 **"安装"** 按钮即可。

**方法 B · 手动复制粘贴**

1. 打开 Tampermonkey 管理面板（点浏览器工具栏的黑色方框图标 → "管理面板"）
2. 点顶部的 "+" 图标（创建新脚本）
3. 把 [sjtu-meeting-toolkit.user.js](https://github.com/treerobin06/sjtu-meeting-toolkit/blob/main/sjtu-meeting-toolkit.user.js) 的内容**全选复制**
4. 回到 Tampermonkey 编辑器，**全选删除**模板，**粘贴**刚才复制的内容
5. 按 **Ctrl/⌘ + S** 保存

### 第 3 步：验证安装成功

1. 打开 [https://meeting.sjtu.edu.cn/my-meeting](https://meeting.sjtu.edu.cn/my-meeting)
2. 用你的 jAccount 登录
3. 页面右下角会出现一个 **🎯 渐变蓝绿色圆形按钮**（这就是工具箱入口）
4. 点击它打开主面板，看到 3 个标签页（📅 批量创建 / 📋 列表与导出 / 📦 预设）就说明成功了

## 🚀 使用流程

### 学期初：一次性创建一整学期会议

```
打开工具箱 → 顶部"📅 学期范围"设起点（开学第一天）+ 周数（比如 16）
         → 切到 📦 tab，把要用的预设打上 "本学期" tag
         → 点 tag 筛选成 "本学期"
         → 点"加载该 tag 全部预设"
         → 切回 📅 tab，几十行任务都已生成
         → "预览全部日期"确认
         → "开始批量创建"
         → 等几分钟，整学期所有会议建好
```

### 每天发群：把当天会议链接广播到微信群

```
打开工具箱 → 切到 📋 tab
         → 点 "📅 今天"（或 "📆 明天"）一键勾选
         → 点 "🔗 含入会链接"
         → 完整邀请文本（含 meeting.tencent.com 链接）已复制到剪贴板
         → 切到微信群，粘贴
```

> 💡 **缓存机制**：第一次提取某个会议的入会链接需要打开详情对话框（每条 ~3 秒），结果会自动缓存到浏览器 localStorage。**第二次提取同一会议就是秒级**，不再开 dialog。

### 期中：临时删除/调整某些会议

```
打开工具箱 → 📋 tab
         → 用主题关键词或日期范围筛选要删的会议
         → 勾选
         → 点 "🗑 删除选中"
         → 二次确认
         → 工具箱用页面原生"批量删除"功能秒级删完
         → 删除前的会议信息（含邀请链接）自动归档到 🗑 回收站
```

## 📋 三个 Tab 详细说明

### 📅 批量创建

每个"任务行"代表一组**重复会议**（如"周三 10:00 RESEARCH_MEETING"）。每行可独立配置：
- 主题
- 密码（默认从全局来）
- 联席主持人 jAccount（多个用逗号分隔）
- 开始/结束日期（默认从全局学期范围算）
- 重复星期（多选）
- 时间
- 时长（0.5 小时 / 1 小时 / ... / 4 小时）

行右侧的 **💾** 把当前行保存为预设，**⎘** 复制行，**✕** 删除行。

### 📋 列表与导出

| 按钮 | 用途 |
|---|---|
| 主题筛选 / 日期范围 | 过滤可见行 |
| 可见全选 / 清空 / 反选 | 批量选择 |
| 📅 今天 / 📆 明天 | 一键勾选当天/次日的所有会议（累加，不清除已选） |
| 📦 按预设勾选 | 选预设 → 自动勾选所有匹配会议（topic 含 + 星期 + 时间一致） |
| **提取选中** | 瞬间生成 snapshot：主题/时间/时长/会议号/密码（不开 dialog，最快） |
| **🔗 含入会链接** | 抓完整邀请文本（含 meeting.tencent.com 链接）。首次每条 ~3 秒，缓存后秒级 |
| **📥 导出 ICS** | 把选中会议生成 .ics 文件下载，导入 Apple Calendar / Google Calendar / Outlook |
| **🗑 删除选中** | 用页面"批量删除"功能秒级删完，删除前自动归档到回收站 |

**自定义输出模板**：在"🎨 模板"栏写自定义文本，占位符 `{topic} {time} {date} {hm} {duration} {code} {pwd} {link} {invite}`。例：

```
明天 {hm} 的「{topic}」，{duration}
入会链接：{link}
会议号 {code}，密码 {pwd}
```

留空 = 用默认 snapshot 格式。

### 📦 预设 / 标签

预设 = 一行任务的可复用模板。每个预设可以打 N 个 tag（"本学期"、"组会"等）。

操作：
- 点 tag chip 筛选
- 点击预设右侧 **加载** = 加 1 行
- 选中多个预设后点 **加载选中**
- 点击 **加载该 tag 全部预设** = 一键加载该 tag 下所有预设
- **编辑** 弹出表单可改所有字段（含 tags）

## 🔑 全局配置（顶部 3 行）

| 设置 | 说明 |
|---|---|
| 📅 学期范围 | 起点（默认今天）+ 周数（默认 4）= 截止日期。新建/加载预设的任务行都用这个范围 |
| 🔑 默认密码 | 新预设/新行密码字段的默认值（默认 `000000`）|
| 🔑 默认联席 | 新预设/新行联席主持人 jAccount（默认见下方课题组成员） |
| 操作间隔 | 批量创建时每次提交后等待秒数（默认 3 秒，避免被风控） |
| 🗑 回收站 | 查看历史删除记录 |
| **应用到所有任务行** | 一键把当前学期范围覆盖到所有任务行的开始/结束日期 |
| **批量补到所有预设** | 选模式 1（仅补空字段）或模式 2（全部覆盖）|

## ❓ FAQ / 常见问题

**Q：脚本能在哪些浏览器上跑？**
A：Chrome、Edge、Firefox、Safari（macOS）都行，只要装了 Tampermonkey。我们主要在 macOS Edge 上测试。

**Q：会议密码默认是什么？**
A：`000000`。你可以在工具箱顶部"🔑 默认密码"改。

**Q：脚本会上传我的数据到第三方服务器吗？**
A：**不会**。所有配置（预设/任务列表/学期范围/邀请链接缓存/回收站）都存在你浏览器本地的 localStorage 里。脚本本身只在 `meeting.sjtu.edu.cn` 域名内运行，不发送任何数据到外部。换浏览器或清浏览器缓存会丢失配置（尚未实现导入导出，欢迎 PR）。

**Q：为什么有些功能要打开 SJTU 详情对话框很慢？**
A：会议的"完整邀请文本"（含 `meeting.tencent.com` 入会链接）只在 SJTU 详情对话框里有，表格列里没有。所以**首次**提取每条 ~3 秒（脚本自动模拟点开"查看" → 抓"复制信息" → 关闭对话框）。**后续**这些数据会被缓存到 localStorage，下次提取秒级。

**Q：我能贡献代码吗？**
A：欢迎 issue / PR。

**Q：工具箱误删了会议怎么办？**
A：SJTU 平台**不支持恢复**。但工具箱在删除前会把会议的完整信息（含邀请链接）自动归档到回收站，你能在 🗑 回收站查到原数据，照着信息重新创建即可。
